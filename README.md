# nba-draft-combine-analysis
### **NBA Draft Combine: Physical Attributes vs. Vertical Jump Performance**

**Project Overview**

This project explores the relationship between NBA players' physical measurements and their vertical jump performance. Using a dataset of 35 selected NBA players, I analyzed whether height and wingspan are associated with standing and moving vertical jump measurements.

Tools Used

Python

pandas — Data organization and analysis

Matplotlib — Data visualization

Google Colab — Coding environment

Analysis Performed

Organized NBA Draft Combine measurements into a dataset.

Created four scatter plots comparing height and wingspan with vertical jump performance.

Calculated correlation coefficients to identify relationships between variables.

Identified the top five players by moving vertical jump.

Examined descriptive statistics and missing data.

Key Findings

The analysis showed negative correlations between height, wingspan, and vertical jump performance.

Height vs. Moving Vertical: -0.584

Wingspan vs. Moving Vertical: -0.602

Height vs. Standing Vertical: -0.403

Wingspan vs. Standing Vertical: -0.337

These findings suggest that taller players and those with longer wingspans generally recorded lower vertical jump measurements within the available sample.

Limitations

Some NBA players had missing measurements, which reduced the amount of data available for certain comparisons. The dataset also contains a selected group of players rather than a representative sample of the entire NBA.

Data Source
